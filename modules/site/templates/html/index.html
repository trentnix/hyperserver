HyperServer is a back-end framework built in Go that can be used to build hypermedia-based applications with a particular focus on HTMX. It's also intended to be usable for non-HTML-based hypermedia including HyperView, but I'm just working on the basics at the moment.

The source code for HyperServer can be found at Github. Use it as you wish, just please let me know if you build anything with it, have any constructive criticisms, or have any ideas about how it can be made better.

About Me

HyperServer is a project by Trent Nix, a technologist and developer that lives in a blissfully boring part of the high plains of the United States. My personal site can be found at trentnix.com.

Inspiration, ideas, and code in HyperServer were frequently borrowed from a number of places, including:

  • Mike Stefanello's Pagoda project, which advertises itself as a "rapid, easy full-stack web development starter kit in Go".
  • Hypermedia Systems, a book by the creators of htmx.
