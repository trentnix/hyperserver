# Reporting a security vulnerability

Email suspected vulnerabilities to Trent Nix at [trentnix@gmail.com](mailto:trentnix@gmail.com). Do not publish exploit details in public issues or pull requests.

Include the affected commit or version, relevant configuration, steps to reproduce, and the potential impact. Remove credentials, tokens, and personal data from examples and logs.

HyperServer is experimental and not production-ready. Please coordinate public disclosure by email so the issue can be investigated and addressed first.
