HyperServer is a Go-based HyperMedia server to facilitate the development of HyperMedia applications.

![Hyper Gopher](hypergo.png)

HyperServer provides a framework to register modules to a HyperServer application. These modules allow routes and handlers to be registered to the application. Modules might also provide other opportunities for extensibility.

HyperServer is intended to provide services and functionality to make building a Hypermedia application easier. These services include, but are not limited to:
- Authentication
- Logging
- Cacheing
- User Management
- Email services
- Tasks
